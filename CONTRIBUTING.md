# Contributing

Report bugs and propose changes through GitHub issues or pull requests. Include reproduction steps and your operating system or browser. Discuss larger changes before implementing them.

Use synthetic data only. Do not include guest lists, project files, real names, allergies or credentials in issues, screenshots, fixtures or commits. Placeholders such as `X`, `Guest 01`, `ABC` and `XYZ` are sufficient.

Follow the [development checks](docs/DEVELOPMENT.md#checks) and repository conventions in [CLAUDE.md](CLAUDE.md). Write code and documentation in English; Finnish interface translations belong in `src/i18n/fi/`.

Contributions use AGPL-3.0-or-later. Submit only work you have the right to license under those terms, and preserve third-party notices. Contributors retain their copyright.
